# TIDAL internals are found

Requires: none

`render/src/exposeTidalInternals*.ts` re-runs TIDAL's module scripts to capture its modules, Redux store and action creators, and `tidalPatches` rewrites a few TIDAL functions. TIDAL updates break this silently. Check it still works on this TIDAL version.

1. `start`.
2. `eval 'Object.keys(luna.core.tidalModules).length'`: TIDAL's modules were captured (expect hundreds).
3. `eval 'Object.keys(luna.core.buildActions).length'`: action creators were captured (expect over a thousand).
4. `eval 'typeof luna.core.reduxStore.getState === "function" && Object.keys(luna.core.reduxStore.getState()).length'`: the store was found.
5. Check each patch in `render/src/tidalPatches.ts` applied. A patch that doesn't match is skipped silently (no log), so look for its replacement text in the code TIDAL runs. `dump` writes TIDAL's sources as served, before Luna's transform: grep `.tidal-test/<n>/sources/render` for each patch's `marker` to see its module is loaded (navigate first if not, e.g. to an album page for drag and drop lists). Then search the transformed modules, as `luna-module://` serves them (`native/injector.ts`), for each replacement:
   `eval '(async () => { const found = { dragSourceRefChurn: [], triggerOnceReobserve: [], overlayScrollbarsNative: [] }; for (const path of Object.keys(luna.core.tidalModules)) { const code = await (await fetch("luna-module://" + location.host + path)).text(); if (code.includes("?this.reconnectDragSource():queueMicrotask(()=>this.reconnectDragSource())}")) found.dragSourceRefChurn.push(path); if (code.includes("triggerOnce:") && /\|\|[\w$]+&&[\w$]+\.current\)return;/.test(code)) found.triggerOnceReobserve.push(path); if (code.includes("globalThis.__lunaNativeScroll(")) found.overlayScrollbarsNative.push(path); } return found; })()'`
   The strings, per patch: "react-dnd dragSource ref churn": `?this.reconnectDragSource():queueMicrotask(()=>this.reconnectDragSource())}`; "react-intersection-observer triggerOnce re-observe": `||<triggerOnce>&&<ref>.current)return;` (the regex above, in a module with `triggerOnce:`); "OverlayScrollbars to native scrolling": `globalThis.__lunaNativeScroll(`. If `tidalPatches.ts` has patches not listed here, check each one's `replace` text the same way.
6. Dispatch one harmless action through Luna and see an interceptor run. Actions Luna dispatches (`luna.lib.redux.actions[type]`) are built from `luna.core.buildActions`, TIDAL's unpatched creators, so they skip interceptors; an intercept on `router/PUSH` would never fire here. Intercept instead the `router/NAVIGATED` that TIDAL's own (patched) creator makes once the push lands, the way `plugins/ui/src/classes/Page.ts` opens Luna's pages: `eval '(() => { const unloads = new Set(); return new Promise((resolve) => { luna.lib.redux.intercept("router/NAVIGATED", unloads, (payload) => resolve(payload.search)); luna.lib.redux.actions["router/PUSH"]({ pathname: "/not-found", search: "lunaAgentTest", replace: true }); setTimeout(() => resolve("timeout"), 5000); }).finally(() => luna.core.unloadSet(unloads)); })()'` (the `finally` removes the interceptor again), then navigate back home with `eval 'luna.lib.redux.actions["router/PUSH"]({ pathname: "/", search: "", replace: true })'`.

Pass when all counts are non-zero, step 5 found every replacement string (each list non-empty; name any patch whose marker is in the dump but whose replacement is missing), and step 6 returns `?lunaAgentTest` (TIDAL adds the `?`; `"timeout"` means no interceptor ran). On a fail, say which step and what TIDAL version (`eval 'navigator.userAgent'`).
